# Bibliometric Analysis of Ulcerative Colitis Pharmacotherapy EvolutionThis repository contains the R scripts and data dictionaries used to analyze the evolution of pharmacotherapy in Ulcerative Colitis (UC). The project utilizes bibliometric methods to track treatment trends, classify drugs by generation, and visualize the shifting landscape of UC research.## 📂 File DescriptionsThe repository is organized into data dictionaries and analysis scripts:### 1. Data Dictionaries (`.txt` / `.csv`)These files serve as reference lists for text mining and data classification.- **`bibliometrix_stopword.txt`**: A custom list of stop words tailored for bibliometric analysis in the medical field. Used to filter out irrelevant terms during keyword extraction.- **`bibliometrix_synonyms.txt`**: A synonym dictionary used to merge equivalent terms (e.g., merging "inflammatory bowel disease" variants) to ensure accurate frequency analysis in the `bibliometrix` platform.- **`drug_synonyms.txt`**: A comprehensive dictionary mapping generic drug names to their brand names and aliases. Used in R to tag literature with specific drug entities.- **`generation.txt`**: A classification dictionary that categorizes UC drugs into different generations (e.g., 1st gen Immunomodulators, 2nd gen Anti-TNF, 3rd gen Small molecules).### 2. Analysis Scripts (`.R`)- **`uc_generation_evolution.R`**: The main script for visualization. It processes the tagged data and generates **stacked area charts** to display the evolutionary trends of different drug generations over time.## 🛠️ How to Use1.  **Prerequisites**: Ensure you have R installed along with the `bibliometrix` package.    ```R    install.packages("bibliometrix")    ```2.  **Data Preparation**: Place your exported bibliographic data (e.g., from Web of Science or Scopus) in the working directory.3.  **Run Analysis**:    - Use the dictionary files (`drug_synonyms`, `generation`) to clean and tag your dataset.    - Run `uc_generation_evolution.R` to reproduce the figures showing the rise and fall of specific drug classes in UC research.## 📄 LicenseThis project is licensed under the MIT License.
